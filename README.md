## So how to use it?
1. Run commands in terminal:
```sh
haxelib remove hscript
haxelib remove hscript-iris
haxelib git hscript-iris https://github.com/TheLeerName/hscript-iris-flixel-debugger
```
2. Put this to `project.xml`:
```xml
<haxelib name="hscript-iris" />
```
4. Now flixel should use HScript Iris instead of original HScript
